```yaml
charter:
  id: CH-catalogue-floor-under-garbage
  mission: "Feed the health verdict every degenerate score line a broken or narrowed catalogue could produce and find the ones it still calls green — this is the mission's own thesis pointed at the mission's own artifact."
  mode: charter-with-tour
  persona:
    name: Mara
    device: laptop
    network: wifi-fast
    locale: pt-BR
  journey: J-health-verdict
  scenarios: [HLT-empty-catalogue-refused, HLT-survivor-refused, HLT-open-gap-refused, HLT-unparseable-score-refused]
  tour: Garbage Tour
  time_box_minutes: 90
  guidance:
    must_try:
      - "score: 0 caught, 0 known gap(s), of 0 — the confirmed hole. Then a narrowed catalogue (of 3), then one mutant, then a count that disagrees with the number of entries in CATALOG=()."
      - "A score line that does not parse at all, and one that parses but has a trailing field — the blind branch must refuse, never skip."
      - "After each red, check the STAMP: a refusal that leaves a stamp on disk is the same defect wearing the fix's clothes."
      - "Compare CATALOG=() entry count against the printed 'of N' — nothing asserts the two agree today."
    must_avoid:
      - "Waiting for a real 20-50 minute catalogue inside the box. Drive the verdict logic with synthesised score lines, and start one real run in the background at minute 0 if a genuine end-to-end reading is wanted."
      - "Fixing the floor during the box — the fix increment F1 already exists in the checkpoint."
```
